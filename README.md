This repository will contain my larger coding projects and the supporting documentation that explains what I built, why I built it, and what I learned along the way.

## Current Focus

## What You Will Find Here

Each completed project will have its own folder and README. Project documentation will normally include:

- Project objective and use case
- Lab environment and tools used
- Setup and implementation steps
- Sanitized screenshots or other supporting evidence
- Problems encountered and how I resolved them
- Security considerations
- Lessons learned and possible improvements
